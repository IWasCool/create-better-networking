# Changelog

## 0.0.2

- Use local network selection, outlines and HUD counts on Create servers without Better Networking.
- Enable full clipboard tools automatically when the mod is installed on both client and server.
- Shift-left-click to select or copy a network; Shift-left-click air to clear the selection.

- Apply copied or named networks with server support while respecting network locks and addon permissions.
- Place untuned factory gauges with server support and assign their networks afterwards.
- Prevent accidental clipboard mining in survival and creative mode.
- Clear stale highlight counts and avoid duplicate network outlines.

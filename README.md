# Create: Better Networking

Source code for a Create addon that provides clipboard tools for logistics networks.

Version **1.0.0 (NeoForge 1.21.1)** targets NeoForge 21.1.255+, Create 6.0.x and Java 21.

The code is available to view, reuse, modify and port under the [MIT license](LICENSE).

## Build and install

Use JDK 21 and run `./gradlew build` (`gradlew.bat build` on Windows). Dependencies resolve from public repositories; the exact Create dependency is recorded in `gradle/mod-dependencies.json`.

The installable JAR is `build/libs/create_better_networking-neoforge-1.21.1-1.0.0.jar`. Install it with the supported Minecraft, NeoForge and Create versions above.

The original [NeoForge MDK notice](LICENSES/NeoForge-MDK-MIT.txt) is retained alongside the project [MIT license](LICENSE).
